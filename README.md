# Домашние тренировки — конструктор

Личное веб-приложение: календарь тренировок + база упражнений со схемой мышц.

## Стек
- React + Vite + TypeScript + Tailwind CSS
- Supabase (Postgres + Auth + Storage) — единая база для всех устройств

## Шаг 1. Настройка Supabase
1. Зарегистрируйтесь на https://supabase.com, создайте новый проект (бесплатный тариф).
2. Откройте **SQL Editor** → New query → вставьте содержимое файла `supabase/schema.sql` → Run.
3. В **Storage** создайте bucket с названием `exercise-media`, сделайте его **public**
   (Settings бакета → Public bucket: on) — иначе фото/видео не будут открываться по ссылке.
4. В **Authentication → Users** нажмите **Add user** и создайте свой единственный аккаунт
   (email + пароль) — это и есть ваш логин в приложение.
5. В **Project Settings → API** скопируйте `Project URL` и `anon public key`.

## Шаг 2. Настройка проекта
```bash
cp .env.example .env
```
Впишите в `.env` значения из Supabase (URL и anon key).

## Шаг 3. Установка и запуск
```bash
npm install
npm run dev
```
Приложение откроется на http://localhost:5173, войдите с email/паролем, созданным в Supabase.

## Шаг 4. Деплой (чтобы пользоваться с телефона тоже)
Самый простой вариант — Vercel:
1. Залейте проект в свой репозиторий на GitHub.
2. На https://vercel.com → New Project → импортируйте репозиторий.
3. В настройках проекта на Vercel добавьте те же переменные окружения
   (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`).
4. Deploy — получите ссылку, откройте её с телефона.

## Структура проекта
```
src/
  components/     — переиспользуемые UI-блоки (Sidebar, карточка упражнения, схема тела)
  pages/          — страницы (Главная, Календарь, Упражнения, форма упражнения)
  lib/            — клиент Supabase, контекст авторизации
  types.ts        — типы данных
supabase/
  schema.sql      — вся схема базы данных, включая права доступа (RLS)
```

## Что уже реализовано
- Вход по email/паролю (Supabase Auth)
- Список упражнений по группам мышц + добавление/редактирование
- Карточка упражнения: фото, видео (YouTube-ссылка или загруженный файл), описание,
  схематическая подсветка задействованной группы мышц
- Календарь: назначение программы тренировки на день, отметка на сегодня
